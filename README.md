# Gerador de Tokens Aleatórios 🔑

Gere tokens seguros, únicos e personalizáveis de forma simples e rápida.

Ideal para:  
- tokens de reset de senha  
- chaves de API temporárias  
- códigos de verificação (OTP-like)  
- identificadores únicos curtos  
- tokens de sessão / refresh token  
- convites / cupons / vouchers

## ✨ Principais características

- Gera tokens com alta entropia (criptograficamente seguros quando possível)
- Vários estilos e formatos prontos
- Tamanho customizável
- Pode excluir caracteres ambíguos (0,O,1,I,l etc.)
- Suporta diferentes alfabetos (hex, alfanumérico, base64-url, etc.)
- Modo CLI e modo biblioteca
- Zero dependências externas (em algumas implementações)
